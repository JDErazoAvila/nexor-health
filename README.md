# NEXOR

Sitio web estático para servicios de analítica financiera, valoración de empresas y soluciones digitales.

## Vista previa local

Abre el archivo `Index.html` en tu navegador o sirve la carpeta con un servidor local.

## Publicación en GitHub Pages

1. Crea un repositorio en GitHub.
2. Conéctalo con este proyecto:
   ```bash
   git remote add origin https://github.com/TU_USUARIO/TU_REPO.git
   git branch -M main
   git push -u origin main
   ```
3. En GitHub, entra a Settings > Pages.
4. Selecciona la rama `main` y la carpeta raíz `/`.
5. Guarda y espera a que GitHub genere la URL pública.

La página quedará disponible en algo como:
`https://TU_USUARIO.github.io/TU_REPO/`
